**一、被动信息搜集**

在渗透测试中，被动信息收集是首要且贯穿始终的环节，其核心原则是**不与目标系统直接交互**，仅通过第三方公开数据源构建目标资产地图。被动收集做得好，后续主动扫描才能有的放矢，且不会惊动目标的防御体系。以下是按维度划分的详细被动扫描清单。



**01 被动扫描首先应获取的关键信息维度**

在触碰目标之前，优先从公开渠道梳理以下五类信息，为后续主动测试划定精确边界：

1. **域名与 IP 基础设施**：WHOIS 注册信息（注册邮箱、NS 服务器）、DNS 记录（A/MX/TXT/NS）。这有助于发现共用同一注册人或 NS 的“兄弟”资产。
2. **子域名与证书透明日志**：通过 crt.sh 等来源查询证书日志，挖掘未在主页链接的测试、开发、管理子域名，这些往往是防护薄弱入口。
3. **暴露的服务与指纹**：利用 ZoomEye 等空间测绘引擎，基于 IP、域名、SSL 证书或协议特征，查找开放端口、服务版本、中间件类型（如 Spring Boot Actuator、Tomcat 管理面板）。
4. **代码仓库与历史泄露**：GitHub 等平台可能因开发者疏忽泄露密钥、内部 API 地址或数据库连接串；Wayback Machine 可发现已删除的测试页面。
5. **组织技术栈线索**：招聘广告中披露的技术框架（如 “熟悉 K8s、Spring Cloud”）能反推目标使用的组件，从而定向排查相关历史漏洞。

在 AI工具辅助进行扫描工作中，提示词质量决定 AI 是否按正确方法论执行。遵循**角色约束 + 数据源限定 + 输出格式**三段式结构。

```
提示词示例：
目标：example.com。执行纯被动侦察。
第一步：查询 crt.sh 获取所有子域名，去重。
第二步：以主域名和去重后的子域名为目标，运行 SpiderFoot passive 模式（-u passive），启用模块 sfp_dnsresolve,sfp_crtsh,sfp_whois,sfp_haveibeenpwned，导出 JSON。解析结果中的 INTERNET_NAME、IP_ADDRESS、LEAKSITE_CONTENT 类型数据。
第三步：对 SpiderFoot 发现的每个独立域名，调用 ZoomEye 查询（domain:"{subdomain}"），fields 限定为 ip,port,app,service,title。
第四步：将全部结果以 Fact 格式写入项目黑板，fact_key 使用 passive:{domain}:{ip}:{port}。若 SpiderFoot 关联规则标记了高风险条目（如泄露数据、恶意 IP），单独列出并附上规则名称。
全程禁止对目标发起任何 HTTP/HTTPS 请求或端口探测。DNS 查询仅限通过公共解析器（如 8.8.8.8）进行，不直接向目标权威 NS 发起查询。
```



**二、主动信息搜集**

主动扫描**直接与目标 IP、端口、服务交互**，获取实时、精确的运行状态。但这也意味着你的行为会留下日志，可能触发防火墙或 IDS 告警。因此，主动扫描必须在授权窗口内，以最小化流量为原则，聚焦于被动阶段已识别的高价值资产进行验证与深度探测。



**01 主动扫描应获取的关键信息**

在被动阶段绘制的资产地图基础上，主动扫描应聚焦以下四类信息：

**1. 实时端口与服务状态**
被动数据可能滞后数月。主动扫描需确认哪些端口**当前**开放、运行什么服务及版本。例如，被动记录显示 8080 端口曾运行 Tomcat 9.0.30，主动扫描需验证该服务是否仍存活、版本是否已更新至修复了已知漏洞的版本。

**2. Web 应用入口与参数**
对已确认的 HTTP/HTTPS 服务，需枚举目录、爬取链接、识别登录入口、API 端点、上传功能等交互点。这些是后续漏洞测试的载体。主动扫描的爬虫会实际请求页面，产生访问日志，因此需控制请求速率。

**3. 服务指纹与配置缺陷**
精确识别中间件类型与版本（如 Apache 2.4.49、Nginx 1.18.0），并检查常见配置问题：目录列表是否开启、管理面板是否无认证暴露、SSL/TLS 配置是否薄弱、是否存在默认凭据。

**4. 授权范围内的漏洞验证信号**
主动扫描可发送少量探测请求来**判断**漏洞是否存在（如发送一个无害的 SQL 引号观察报错、请求一个不存在的路径观察 404 与 500 的差异），但不应执行完整的利用链。这一阶段的目标是确认“值得深入测试”的候选点，而非获取 shell。

范围：仅项目黑板中 passive: 资产，排除 cdn_suspect: true 的 IP。速率 ≤10 req/s，禁碰 /logout、/delete、/admin/delete。
